# Automated tests — reserved

This directory is reserved for future **automated software tests**.

The current ESP32/Wokwi component checks are manual diagnostics and live in
[`diagnostics/`](../diagnostics/). They require observing simulator or
physical-hardware behavior and must not be presented as automated proof that
the complete application passes.

No automated test suite is implemented here yet. When one is introduced, its
scope and limitations should be documented separately from the manual
diagnostics.
