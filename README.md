# esp32-asyncio

ESP32 (MicroPython) practical assessment — Instrumentation, Electronics
and Programming Logic.

> **🚧 Project status:** the original mandatory assessment is complete and
> stable (two LEDs, a push-button, one OLED). The hardware and code shown
> here have since been extended experimentally — more LEDs, a second
> OLED, a TFT display, extra buttons, and more — and that part is **still
> actively changing**. See `technical-specification.md`'s "Extended
> features" section ([English](docs/EN/technical-specification.md) ·
> [Português](docs/PT/technical-specification.md)) for the current state.
